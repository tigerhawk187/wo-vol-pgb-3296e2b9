How to read this

Intake = opportunities received through the Commercial toll-gate (HubSpot deals created since Jan 1, 2025). Transferred to Lift = closed-won deals that became actionable field work. Win rate (resolved) = won ÷ (won + lost), excluding deals still in flight — the cleaner read of competitive performance. CATL is shown separately: its flow largely bypasses Commercial and opens directly in Lift, so it has no bidding funnel and no win rate. Its dispatch volume sits next to the others for context only.

Data notes & how this becomes the production report

Sources: CATL from Renewance Lift (QuickBase, app btctjiyp3, CATL Work Orders table). Sungrow, Risen, LG from HubSpot deal creation, dealname token-matched per vendor. Pulled 03 Jun 2026 — CATL series carried forward from prior run (Lift sign-in still expired — needs manual sign-in then re-run); OEM series refreshed.
Metrics: CATL counts work-order records by Date Created. Other OEMs count HubSpot deals by createdate. Different units — the two sections are kept separate for that reason.
Data quirks: Two CATL weeks carry bulk loads (11-17-2024: 357 / 09-28-2025: 217) — not real intake, excluded from trend reads. LG figures exclude 42 deals authored via commercial-team and Sales-Extension routing (HubSpot users 67667353 + 67779836, primarily Dec '25 NextEra portfolio of 28). Trade-off: this also drops some real wins created through the extension (e.g. Roccasecca Boulder City physical inspection) — LG totals now show only deals authored by user 75077893. Adding a custom deal_source property in HubSpot would let us filter cleanly without that trade-off. Sungrow and Risen unfiltered.
Cadence: auto-refresh every Monday ~2:03 AM Central (scheduled task flow-wo-weekly-refresh). The Monday run pulls Lift for CATL and HubSpot for the others; if Lift isn't signed in, it refreshes HubSpot and flags CATL for a manual sign-in.
Open item: the Lift Projects table has no OEM field, which is why Sungrow / Risen / LG come from HubSpot. Adding an OEM field in Lift would put every OEM on one authoritative source — see the Implementation Plan, Section 10.
